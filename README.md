# Student Record Management System

A menu-driven application developed using C programming to manage student records.

This project uses a *Singly Linked List* to store student details. It also uses dynamic memory allocation and file handling to manage records.

## Features
* Add new student records with automatically assigned unique roll numbers.
* Display all student records in tabular format.
* Delete records using roll number or name.
* Modify student details.
* Sort records by name or percentage.
* Reverse the singly linked list.
* Delete all student records.
* Save and load student records using file handling.

## Concepts Used
* C Programming
* Structures and Pointers
* Singly Linked Lists
* Dynamic Memory Allocation (malloc() and free())
* File Handling
* Modular Programming
* Searching and Sorting

## Compilation
Open the project folder in the terminal and execute:
  make
This compiles the source files and generates the executable named student.

## Execution
Run the application using:
  ./student
The main menu will be displayed. Select the required option to perform different operations.

## File Handling
Student records are stored in a file named `student.dat`. Previously saved records are automatically loaded when the program starts.

Through this project, I learned how to implement singly linked lists, work with pointers, manage dynamic memory, use file handling and develop modular C programs.
